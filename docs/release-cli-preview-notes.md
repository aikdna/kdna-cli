# Native CLI preview change notes

## CLI 0.39.0-rc.native-sections.3

This preview binds the native-section CLI to the exact Core
0.37.1-rc.browser.1 and Read 0.11.2-rc.browser.1 companions. It supports explicit
local creation, admission inspection, catalog and selected reads, optional
expansion in one read session, and source opening, editing and repacking into a
new asset while preserving the original. The packaged team-update example
exercises this complete route from installed package bytes.

Local permission and successful source processing do not establish authorship,
human confirmation, Creation completion, useful-task adoption or action
approval. Native tuple and browser protection tuple remain separate contracts.
This is a preview with the scope stated in the package documentation; it does
not declare all hosts, protected browser integrations or application workflows
accepted. It is published only on `native-preview` after the exact Core and Read
bytes are available from the public npm registry. The stable `latest` tag is
preserved.
